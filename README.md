# AgroCluster Analytics v3.0 — Платформа провайдингу наукових інновацій ТОВ «ІІБ» та НААН України

Цифрова екосистема комерціалізації селекційних розробок за алгоритмом **«Наукова Новація (За кадром) → Драфт ІІБ (Матриця Маржі) → Договірний Кластер (Радіус 50 км) → Вирізка Стартап-лотів»** на прикладі сорту гірчиці білої **«Біла Принцеса»** (ННЦ «Інститут землеробства НААН», Патент №180923, Свідоцтво №180501).

## Ключові архітектурні модулі (Версія 3.0 — Firebase Hosting + Google Cloud Run + Data Connect)

1. **Дворівнева архітектура Драфту ТОВ «ІІБ» ([`index.html`](index.html), [`script.js`](script.js)):**
   - **Мета-рівень (Надбудова НАД ланцюгом):** ТОВ «Інститут інноваційної біоекономіки» (Інноваційний провайдер / «Продюсерський центр») — перекладає наукову розробку на мову маржі, вигоди та договорів.
   - **4 внутрішні технологічні капсули (за даними `1_Драфт.pptx`):**
     - *За кадром (1 га):* Оригінальне насіння та Супереліта НУС НААН (вал 1,5 т $\rightarrow$ 1,0 т стартова опція масштабування).
     - *Капсула І (200 га):* Базове насінництво Еліти у ДГ/БГ (120 т кондиційної Еліти + 180 т технічної фракції).
     - *Капсула ІІ (300–5000+ га):* Фермерський пул СН-1/СН-2 у радіусі 50 км (роялті НААН: 800 / 200 / 100 грн/га).
     - *Капсула ІІІ (Подвійний вихід):* **Вихід А — Сидерат** (фасування у мішки 25 кг по 42 000 грн/т, азот, біофумігація проти нематод) + **Вихід Б — Глибока переробка Zero-Waste** (порошок 50%, олія 30%, шрот 15%, експорт у Німеччину та Нідерланди).
2. **Парсер та верифікатор юридичних осіб за ЄДРПОУ — Тільки Аграрії ([`agro_registry_service.py`](agro_registry_service.py)):**
   - Автоматичний парсинг за 8-значним кодом ЄДРПОУ та жорсткий секторальний фільтр КВЕД-2010 (`01.xx`, `10.41`, `10.61`, `10.84`, `10.91`, `20.15`, `46.21`, `72.11`, `72.19`).
   - Відсікання неаграрних компаній (`NON_AGRO_REJECTED`).
   - **Правило комерційного Оператора подачі:** при виборі бюджетної установи НААН (`00496802`) офіційним Заявником на грант автоматично призначається комерційний Провайдер **ТОВ «ІІБ» (`40125890`)**, а НААН фіксується як Ліцензіар ОІВ.
3. **Хмарна інфраструктура Firebase + Cloud Run + Data Connect:**
   - [`firebase.json`](firebase.json) та [`.firebaserc`](.firebaserc) — хостинг фронтенду та проксіювання API-запитів на контейнер Cloud Run (`agrocluster-api`).
   - [`Dockerfile`](Dockerfile) — контейнер FastAPI (`main.py`) для Google Cloud Run.
   - [`dataconnect/`](dataconnect/dataconnect.yaml) — GraphQL-схема та конектори Firebase Data Connect (PostgreSQL).
4. **Автоматизоване тестування ([`tests/test_agrocluster.py`](tests/test_agrocluster.py)):**
   - Запуск тестів: `python3 -m unittest discover -s tests -v` або `pytest tests/test_agrocluster.py -v`.
