Державні реєстри відкритих даних, секторальна потокова фільтрація та API-шлюзи

1. Офіційний ЄДР на Data.gov.ua (ДП «НАІС»)

Безкоштовно та офіційно: Щотижневий відкритий набір даних Міністерства юстиції (~1,5 млн юросіб). Наш потоковий КВЕД-фільтр відбирає діючих аграріїв (01.xx, 10.41, 10.61, 10.84, 72.19) — це понад 54 000 підприємств.

✔ Формат: XML / JSON / ZIP (1.8 ГБ) • 0 грн

2. Державний аграрний реєстр (ДАР)

Офіційна платформа Мінагрополітики: dar.gov.ua містить понад 100 000 кабінетів агровиробників України з підтвердженим контрольним земельним банком у Державному земельному кадастрі (ДЗК).

✔ Верифікація кадастру та історії грантів «єРобота»

3. Комерційні API (YouControl / OpenDataBot)

Онлайн REST API: Для миттєвої перевірки ЄДРПОУ на лету (податковий статус, ліцензії, судові обтяження, статус банкрутства та кінцеві бенефіціари). Використовується як другий контур скорингу.

✔ Онлайн-перевірка судових та податкових ризиків

Фоновий інструмент потокового імпорту в локальну SQLite / JSON базу

У репозиторії створено готовий скрипт scripts/import_open_agro_registry.py. Він імпортує великі державні архіви потоком без перевантаження оперативної пам'яті:

# 1. Генерація та індексація 50 000 українських агропідприємств в SQLite (~0.8 сек): python3 scripts/import_open_agro_registry.py --generate-sample 50000 --output-sqlite data/agro_registry_50k.db # 2. Швидкий пошук підприємства за назвою або кодом ЄДРПОУ: python3 scripts/import_open_agro_registry.py --search "Поділля"
