Архітектура інтеграції державних реєстрів, потокова фільтрація відкритих даних та API-шлюзи

1. Офіційний ЄДР на Data.gov.ua (ДП «НАІС»)

Безкоштовно та легально: Міністерство юстиції щотижня публікує повний реєстр усіх юросіб (~1,5 млн записів). Наш потоковий фільтр відбирає лише діючих аграріїв (КВЕД 01.xx, 10.41, 10.61, 10.84, 72.19) — це понад 54 000 підприємств.

✔ Формат: XML / JSON / ZIP (1.8 ГБ) • 0 грн

2. Державний аграрний реєстр (ДАР)

Офіційна платформа Мінагрополітики: dar.gov.ua містить понад 100 000 кабінетів верифікованих агровиробників України з інформацією про земельний банк у ДЗК, поголів'я та історію участі в програмах держпідтримки «єРобота».

✔ Верифікація земельного банку та кадастру

3. Комерційні API (YouControl / OpenDataBot)

Швидкий REST API: Для миттєвої перевірки ЄДРПОУ на лету (податковий стан, наявність ліцензій, судові обтяження, статус банкрутства та дійсні бенефіціари). Використовується як додатковий скоринг-шар.

✔ Онлайн-перевірка судових та податкових ризиків

Автоматизований фоновий імпорт у локальну базу SQLite / JSON

У репозиторії створено готовий високопродуктивний інструмент scripts/import_open_agro_registry.py. Він здійснює потоковий імпорт великого архіву без перевантаження оперативної пам'яті та створює індексовану базу 50 000+ підприємств:

# 1. Генерація та індексація 50 000 українських агропідприємств в SQLite (займає ~0.8 сек): python3 scripts/import_open_agro_registry.py --generate-sample 50000 --output-sqlite data/agro_registry_50k.db # 2. Швидкий пошук агропідприємства за назвою або ЄДРПОУ: python3 scripts/import_open_agro_registry.py --search "Поділля" # 3. Довідка про структуру та офіційні URL набору на Data.gov.ua: python3 scripts/import_open_agro_registry.py --info
